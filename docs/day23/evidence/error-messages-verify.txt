### 第一类｜入参校验（400）

============================================================
## 1a POST /api/favorites 缺 workId
$ -X POST http://127.0.0.1:3010/api/favorites -H Content-Type: application/json -d {"userId":"demo"}
---- 响应体 ----
{
  "ok": false,
  "error": "missing_work_id",
  "message": "缺少必填字段 workId（要收藏的作品编号，例如 music-1）"
}
[HTTP_STATUS]=400

============================================================
## 1b POST /api/favorites workId 格式错
$ -X POST http://127.0.0.1:3010/api/favorites -H Content-Type: application/json -d {"userId":"demo","workId":"@@@"}
---- 响应体 ----
{
  "ok": false,
  "error": "invalid_work_id_format",
  "message": "workId 格式不对，应形如「板块-编号」，例如 music-1、video-2"
}
[HTTP_STATUS]=400

============================================================
## 1c PATCH 空 body（至少给一个字段）
$ -X PATCH http://127.0.0.1:3010/api/favorites/1 -H Content-Type: application/json -d {}
---- 响应体 ----
{
  "ok": false,
  "error": "empty_patch",
  "message": "请求体是空的，至少要给出一个要修改的字段（目前支持：note）"
}
[HTTP_STATUS]=400

============================================================
## 1d POST 非法 JSON
$ -X POST http://127.0.0.1:3010/api/favorites -H Content-Type: application/json -d {bad json
---- 响应体 ----
{
  "ok": false,
  "error": "invalid_json",
  "message": "请求体不是合法的 JSON，请检查格式（引号、逗号、括号）"
}
[HTTP_STATUS]=400

============================================================
## 1e works 分类传错
$ http://127.0.0.1:3010/api/works?category=nope
---- 响应体 ----
{
  "ok": false,
  "error": "invalid_category",
  "message": "category 只能是：music / doujin / game / video / art",
  "valid": [
    "music",
    "doujin",
    "game",
    "video",
    "art"
  ]
}
[HTTP_STATUS]=400

### 第二类｜资源不存在（404）

============================================================
## 2a PATCH 不存在的 id
$ -X PATCH http://127.0.0.1:3010/api/favorites/99999 -H Content-Type: application/json -d {"note":"x"}
---- 响应体 ----
{
  "ok": false,
  "error": "favorite_not_found",
  "message": "没有找到 id=99999 的收藏，可能已经被取消了"
}
[HTTP_STATUS]=404

============================================================
## 2b DELETE 不存在的 id
$ -X DELETE http://127.0.0.1:3010/api/favorites/99999
---- 响应体 ----
{
  "ok": false,
  "error": "favorite_not_found",
  "message": "没有找到 id=99999 的收藏，可能已经被取消了"
}
[HTTP_STATUS]=404

============================================================
## 2c POST 作品不存在
$ -X POST http://127.0.0.1:3010/api/favorites -H Content-Type: application/json -d {"userId":"demo","workId":"music-999999"}
---- 响应体 ----
{
  "ok": false,
  "error": "work_not_found",
  "message": "作品 music-999999 不存在，请先确认 workId 是否正确"
}
[HTTP_STATUS]=404

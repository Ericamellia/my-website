Day 20 · 浏览器真实网络请求记录

来源：Edge DevTools Protocol（Network domain）实时抓取 · 页面 https://touhou-mock.app.workbuddy.host/ · 抓取时间 2026-10-10

方法请求 URL状态类型远端 IP
GET https://touhou-mock.app.workbuddy.host/api/hot?board=fresh&limit=12 200 Fetch 49.233.240.214
GET https://touhou-mock.app.workbuddy.host/api/favorites?limit=20 200 Fetch 49.233.240.214
GET https://ericamellia24-d2gk0ftukc71292c5.service.tcloudbase.com/api/health 200 Fetch 124.223.146.214
关键判读：第三条请求的域名是 *.service.tcloudbase.com——这是 CloudBase 云函数 HTTP 访问服务的公网地址，不是本站域名， 证明 health 卡片确实在跨域直连云函数。
它的远端 IP 124.223.146.214 与本站 Node 服务 49.233.240.214 是两台不同的机器—— 若请求走的是本站代理或本地 mock，IP 必然相同。IP 不同 = 真的跨出去了。

复现方式：cd shots && python cdp_net.py <url> <out.png> · 抓取脚本 shots/cdp_net.py
